# Additional research questions

These are optional research directions for lead selection, not changes to the accepted query contract or release requirements. Preserve the working prototype while evaluating them.

## Plot support and review interpretation

Question: can reasonable spatial selection methods change a mapped-loss screening result on the supplied small plots?

Compare the accepted native-cell-center rule with cells whose footprints have positive-area intersection with each original polygon. Keep zero-area boundary contact separate. Use the same pinned Hansen values, masks and observation periods; do not change the source or label either method as the company's undocumented rule. Report per-plot selected cells, observed loss cells, unknown support, and any changed period flag. Boundary fixtures and any geometry perturbations must be labelled synthetic and separate from the 17 original plots. Counts and geographic-coordinate area fractions are not surveyed hectares or legal findings.

A useful outcome is an inspectable boundary witness explaining why an overlap analysis might differ, or evidence that this particular method difference does not explain the supplied declarations. This would complement the already demonstrated floating-point window-origin regression, which is an implementation error rather than an intentional change of spatial rule.

## Publication revision versus observation year

If later acquisition is justified, compare explicitly named historical and current Hansen releases over their shared observation years. An older release is not automatically the supplier's original data vintage. Future years absent from an old release are unavailable, never no-loss zeros. Keep release changes separate from real annual events and encoding mismatches. A no-change result on the plots is informative; do not manufacture a disagreement narrative.

## Fixed-cohort cache versus general spatial store

An exact cache of the selected cells or results for known farms could be much smaller than an entire regional store. Its supported query family is narrower: a new polygon or changed rule may require original data again. Any experiment must disclose that capability difference, count geometry/index/source-version metadata, reject unsupported queries, and never advertise fixed-cohort reduction as general-purpose regional compression. Consider this only if the core general store and its measurements are already stable.
