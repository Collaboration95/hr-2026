## Stable envelope

`schema_version: "plotline.demo.v1"`, `query_version: "hansen-centers.v1"`, `dataset` (source metadata, hashes, grid), `periods` (2021–2023 and 2024–2025), `plots` (17 joined records), `summary`, `benchmark` (null until measured), `limitations`.

Each plot: `plot_id`, `geometry` (exact GeoJSON geometry), `supplier` (all exact CSV string fields), `source_result`, `compact_result`, `comparison` (`equal`, `differing_fields`, `source_result_sha256`, `compact_result_sha256`), `receipt`, `evidence` (GeoJSON FeatureCollection of selected native cells, properties `row`, `col`, `treecover2000`, `lossyear`, `datamask`, `valid_land`). GeoJSON coordinates are EPSG:4326. Cell polygons are whole native-grid footprints; their *centers* are selected with polygon `covers`, not clipped overlap polygons.

Query result: `selected_cell_count` includes centers outside the available chip; `in_coverage_cell_count`, `out_of_coverage_cell_count`, `valid_land_cell_count`, `unknown_cell_count`, `datamask_counts` keys `0`, `1`, `2`; `canopy_histogram` length 101 or null; `lossyear_histogram` length 26 or null (index 0 = no mapped loss; index 1 = 2001); `yearly_loss_counts` keys `2001`…`2025` or null; `periods` keys `2021-2023`, `2024-2025` each `{mapped_loss_present: true|false|null, observed_loss_cell_count: integer|null}`; `support: "complete"|"partial"|"none"|"unavailable"`; `unknown_reasons` string array.

## Resolved partial-support ambiguity

The v0 proposal simultaneously says partial histograms should be labelled observed counts and that any outside coverage makes analytical outputs null. v1 chooses monotonic observed evidence: retain histograms on available valid land when part of a polygon is outside coverage or nodata. A witnessed period loss is true even with partial support. With no witnessed loss, false requires complete selected support and at least one valid land cell; otherwise null. Thus partial unknown never becomes false. Zero selected cells, no valid land, or any missing required band makes analytical histograms and flags null. Available diagnostic mask counts remain. Tests cover each distinction. This is an explicit engineering rule change, not company-confirmed semantics.

`unknown_reasons` may include `no_selected_cells`, `out_of_coverage`, `nodata`, `band_mask_invalid`, `no_valid_land`, `missing_band:<name>`. Counts are observed cells, never hectares or complete polygon area. Water is known support but is not valid land. Missing required bands globally disable the analytical answer.

## Display semantics

Supplier values are declarations, not findings. `lossyear` is mapped tree-cover loss, not legal deforestation. Canopy is year-2000 context, not forest-2020. Hansen release is 2025 v1.13, distinct from supplier historical source vintage. Reference keys are opaque, not URLs. Source/compact equality establishes encoding fidelity, not source accuracy. Unknown cannot display as clear/compliant.

Representative real example will be generated at `artifacts/example-v1.json` with the first complete slice. Uncomputed metrics remain null; no fabricated placeholder measurements.

## Optional unknown-state lab

`artifacts/synthetic-v1.json` is a separate, explicitly synthetic six-case export. Each case has case_id, synthetic=true, geometry, missing_bands, result, evidence. It uses a fictitious4×4grid and must never be merged into real cohort metrics. Useful for inspecting unknown/partial/no-support UI behavior; no real-observation claim attaches to these cases.

Missing-band diagnostics are explicit: the named band is treated as globally invalid. Therefore valid_land_cell_count becomes0, unknown_cell_count equals selected_cell_count, and band_mask_invalid/no_valid_land reasons appear when covered in-chip centers exist. If datamask itself is missing, its diagnostic counts are all0; if another band is missing, known datamask counts are retained. Zero selected centers still has no_selected_cells and missing_band reasons. This is distinct from stored raw masked values, which the codec preserves.
