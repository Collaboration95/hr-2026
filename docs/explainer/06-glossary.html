Affine transform

A fixed rule from grid addresses to map coordinates. Like a ruler starting at a known corner. Six coefficients allow scale, rotation and translation; Plotline accepts north-up, unrotated EPSG:4326 grids.

engine/query.py → select_cells()See it explained →

Answer table

Stored outputs for registered plots. Like keeping the completed calculation sheet. Lookup checks plot ID, geometry hash, store hash and contract level; this path cannot answer an unseen boundary.

engine/decision_index.py → build_table(), table_lookup()See it explained →

Array

An ordered block of values. Like numbered boxes on shelves. Hansen values and boolean masks use a [3, height, width] NumPy shape; one address is [band, row, column].

engine/source.py → load_source()See it explained →

Band

One attribute on a raster grid. Like one sheet in a stack of graph paper. The Hansen canopy, loss-year and datamask attributes are separate single-band files, stacked after reading.

engine/source.py → load_source()See it explained →

Bit-plane

One yes/no layer extracted from values. Like keeping one checkbox from every form. Packing eight bits per byte can represent sparse spatial facts compactly; decision encoding separates land, water and forest-related bits.

engine/decision_store.py → _split_parts(), _put_plane()See it explained →

Byte

Eight binary digits, called bits. Like a small box with 256 possible labels. A uint8 array uses one byte per value before compression; file sizes also include headers and other metadata.

engine/decision_store.py → write_store()See it explained →

Canopy closure

The share of ground covered by tree crowns when viewed from above. Like the shaded fraction under a tree umbrella. Hansen treecover2000 holds integer percentages from 0 to 100 for vegetation taller than 5 m in 2000.

engine/query.py → summarize_selected()See it explained →

Cell / pixel

One square of a raster array. Like a square of graph paper. Its value describes a footprint on Earth; the written selection rule tests the footprint’s centre. Counts of cells are not hectares.

engine/query.py → select_cells()See it explained →

Centre rule

Keep a raster cell when the polygon covers its centre. Like choosing pegs inside a loop of string. Exterior and hole boundaries count; hole interiors do not. It differs from an any-footprint-overlap rule.

engine/query.py → select_cells()See it explained →

Chip

A rectangular cut-out from a larger raster. Like a cropped atlas page. The acquired Hansen chip keeps the native spacing and has 1,233 columns × 604 rows. Its transform records the shifted origin.

engine/source.py → open_sources()See it explained →

Codec

An encoding and decoding recipe. Like a reversible packing method. A lossless codec restores identical values; choosing a better codec does not itself change the later selection algorithm.

engine/codecs.py → encode_store(), decode_store()See it explained →

Cold start

Starting without a loaded process state. Like opening the kitchen for the day. Here distinguish fresh-process load + query after imports from end-to-end Python start-up including imports. Neither benchmark controls a disk-cold OS cache.

engine/decision_benchmark.py → _cold(), _e2e()See it explained →

Compression

Storing the same information with fewer bytes. Like abbreviating repeated instructions. Lossless compression keeps values exactly; decision-layer derivation first drops attributes outside the written query contract, then compresses the retained facts.

engine/decision_store.py → encode_codes(), decode_codes()See it explained →

Contract / query rule

The exact question and permitted outputs. Like an agreed checklist before doing an audit. The screening contract and smaller decision contract retain different facts; interpreting a raster at the wrong level can change an answer.

engine/decision.py → SCREEN_VERSION, DECISION_VERSION, bind_level()See it explained →

Covers

A boundary-inclusive geometry predicate. Like counting a peg on the string as inside the fence. Shapely covers selects centres in the polygon or on its boundary, including a hole boundary.

engine/query.py → select_cells()See it explained →

CRC32

A 32-bit checksum for accidental corruption. Like a short check digit on a parcel label. The decision-store format checks the header with it. It is not a signature and does not stop deliberate forgery.

engine/decision_store.py → _file_bytes(), read_store()See it explained →

CRS

Coordinate reference system: the convention that gives numbers a location. Like specifying which address system a street number belongs to. This query requires EPSG:4326 and a north-up grid.

engine/query.py → select_cells()See it explained →

Cut-off date

The line between the baseline and later change. Like the date of a before photograph. This use case asks for mapped forest on 31 December 2020 and available later loss from 2021 to 2025.

engine/decision.py → CUTOFF_LOSSYEAR, POST_YEARSSee it explained →

Datamask

A grid classifying land context. Like labelling atlas squares as land, water or unavailable. Hansen codes are 0 nodata, 1 mapped land and 2 permanent water; this is distinct from each band’s validity mask.

engine/query.py → summarize_selected()See it explained →

Decision layer

A reduced raster holding the facts needed for the selected decision. Like a checklist copied from a large case file. eudr-decision.v1 forgets loss years on JRC-mapped 2020 non-forest land. It is exact on its written outputs, not all original values.

engine/decision.py → project_decision()See it explained →

DEFLATE

A lossless compression method. Like referring back to repeated text and coding common symbols briefly. It is a standard GeoTIFF control here, not the only recipe a GeoTIFF can use.

engine/decision_store.py → _geotiff_controls()See it explained →

Entropy

A measure of uncertainty in values. Like how hard a sequence is to predict before reading it. It helps explain compressibility. These reports show practical codec controls, not a proven universal lower bound for the canopy raster.

engine/codecs.py → encode_store() provides measured lossless candidatesSee it explained →

EUDR

EU Deforestation Regulation. For this project it motivates a mapped forest-at-cut-off and later-loss screen. Like one checklist within a wider review, that screen is only part of a legal assessment. Plotline does not issue a compliance verdict.

engine/decision.py → summarize_counts()See it explained →

Exhaustive check

Compare every member of a finite set. Like checking every tile in a mosaic rather than a few samples. Here the proof compares all 744,732 cell codes at both contract levels against an independent original-layers path.

engine/decision_proof.py → exhaustive()See it explained →

Fidelity

Agreement between an original and an encoded representation. Like checking a copied answer sheet. Decision fidelity checks all output fields; raw pixel fidelity checks original values and masks. A reduced decision layer must state what it drops.

engine/decision_proof.py → compare_codes(), plot_proof()See it explained →

Fuzzing

Testing many generated inputs, especially awkward ones. Like trying thousands of oddly shaped keys. The proof generates synthetic polygons with holes, boundary cases and multiple parts, then compares the two paths.

engine/decision_proof.py → Fuzz, fuzz()See it explained →

GDAL / rasterio

GDAL is a geospatial file library; Rasterio is its Python-facing reader here. Like a translator for map-file formats. load_source uses them to decode original TIFF values and masks into NumPy arrays.

engine/source.py → open_sources(), load_source()See it explained →

GeoJSON

A text format for geographic geometry and properties. Like a list of pegs and the order to join them. Polygon positions are [longitude, latitude] here, with explicitly closed rings; extra rings are holes.

engine/query.py → select_cells() validates the geometrySee it explained →

GeoTIFF

A TIFF image with geospatial metadata. Like a numbered mosaic with an address label. It records grid dimensions, type, coordinate system and transform; pixel blocks may be compressed and overviews are optional.

engine/source.py → open_sources()See it explained →

Hansen GFC

Hansen Global Forest Change, the public tree-cover dataset used here. Like a yearly change log tied to grid addresses. Version 2025 v1.13 supplies treecover2000, lossyear 0–25 and datamask. Loss is not a legal deforestation finding.

engine/source.py → open_sources()See it explained →

Hash

A digest computed from content. Like a reproducible fingerprint for a file or shape. A changed digest detects a changed input. Self-hashes do not establish who supplied the data; genuine identity needs a trusted pinned hash.

engine/source.py → sha256_file(), object_hash()See it explained →

Histogram

Counts for each value or category. Like counters sorted into labelled jars. v1 uses 101 canopy bins and 26 loss-year bins; the decision reducer uses 20 code bins.

engine/query.py → summarize_selected()See it explained →

Hole

An excluded interior ring within a polygon. Like a pond cut out of a field outline. Centres strictly inside the hole are excluded; the hole boundary itself counts under covers.

engine/query.py → select_cells()See it explained →

Hot path

Repeated query work after loading and decoding. Like cooking with ingredients already on the bench. v1’s compact and original paths use the same arrays and selection/reduction work once hot.

engine/decision_benchmark.py → _hot()See it explained →

Index

Stored information that avoids repeating a search. Like a book’s list of page locations. The registered-plot index stores selected flat cell addresses, bound to a geometry hash and grid identity. It still reduces the current raster values.

engine/decision_index.py → build_registry(), registry_evaluate_store()See it explained →

JRC GFC2020

Joint Research Centre Global Forest Cover 2020, v4 here. Like a mapped snapshot of forest at the cut-off. Its about-10-m forest/non-forest cells are sampled at Hansen centres; the checked native grids nest 3:1.

engine/decision.py → nested_offsets(), derive_screen_codes()See it explained →

Latitude / longitude

Angular coordinates on Earth. Like north–south and east–west address lines. Latitude runs north/south and longitude east/west. GeoJSON and the raster x/y convention here use longitude first; degree widths are not constant ground distances.

engine/decision_original.py → cell_attributes()See it explained →

Lossless / lossy

Whether discarded information can be recovered exactly. Like keeping a full transcript versus a summary. v1 is lossless for raw values and masks; the decision layer loses unused detail but preserves its declared query outputs exactly.

engine/decision.py → project_decision()See it explained →

Lossyear

Hansen’s year code for mapped loss. Like a year stamp on a grid square. Zero means no mapped loss; 1–25 means 2001–2025. Masked values remain unknown, even when their stored numeric value is zero.

engine/query.py → summarize_selected()See it explained →

LZMA / LZMA2

Related lossless compression methods; LZMA2 is a chunked form used by candidate decision encodings. Like a more elaborate repeated-pattern packing recipe. The decision codec tests tuned raw LZMA2 streams against zstd and uncompressed bytes.

engine/decision_store.py → _pack_stream(), _lzma_filters()See it explained →

LZW

A dictionary-based lossless compressor. Like assigning short labels to repeated phrases. It is one of the standard GeoTIFF controls, alongside DEFLATE, ZSTD and LZMA.

engine/decision_store.py → _geotiff_controls()See it explained →

Mask

A marker saying whether an observation is valid. Like a checkbox beside a form field. Band masks are boolean arrays; a false entry is unusable. In the current derivation all three Hansen masks still matter, even though canopy values are dropped.

engine/decision.py → derive_screen_codes()See it explained →

Materialised view

A stored answer to a calculation. Like keeping a completed total rather than adding the receipt again. Plotline’s answer table stores both contracts for registered plots and must miss when its identifying inputs change.

engine/decision_index.py → build_table(), table_lookup()See it explained →

Metadata

Data describing the data. Like the label on a box. For a raster it includes shape, data type, transform and CRS; for evidence it also includes versions and hashes. Wrong grid metadata can change a query even if pixel bytes stay the same.

engine/source.py → open_sources()See it explained →

MultiPolygon

A geometry made of separate polygon parts. Like one farm with two disconnected fields. Selection keeps the union of covered centres without counting the same centre twice.

engine/query.py → select_cells()See it explained →

Negative control

A deliberately broken case that the test must catch. Like planting a wrong answer to check that marking works. The proof changes codes, geometry or JRC facts and verifies the mismatch is detected.

engine/decision_proof.py → negative_controls()See it explained →

Nodata

No usable mapped observation. Like a blank form response. It may be represented by a missing-data value, an invalid band mask, or Hansen datamask 0. A valid zero loss-year is a different state.

engine/query.py → summarize_selected()See it explained →

NumPy

Python’s array-computing library. Like a calculator that works on a whole shelf of numbers at once. The engine uses its arrays for bands, masks, selecting values and counting categories.

engine/query.py → summarize_selected()See it explained →

Overview

A lower-resolution copy in a raster file. Like a thumbnail. It can speed display when zoomed out; Plotline’s original query reads the native band values, not an overview-based approximation.

engine/source.py → load_source() reads src.read(1)See it explained →

Polygon

A closed boundary enclosing an area. Like string around pegs. It has an exterior ring and optional holes; select_cells requires finite two-coordinate positions, explicitly closed rings and valid nonempty geometry.

engine/query.py → select_cells()See it explained →

Provenance

The record of where data came from and how it was handled. Like a parcel’s chain of labels. It includes source versions, hashes, acquisition windows, grid details and readback checks. It supports replay; it is not ground truth.

engine/source.py → open_sources()See it explained →

Raster

A regular grid of numbered cells. Like graph paper holding one value per square. The transform and CRS place it on Earth. A raster’s displayed colours are a visual mapping of values.

engine/source.py → load_source()See it explained →

Receipt

A record binding an answer to inputs and a rule. Like a calculation’s attached working sheet. v1 receipts include source identities, grid, geometry digest, rule and compact-store information. Self-hashes are integrity checks, not signatures.

engine/proof.py → receipt_for()See it explained →

Reduction

Combining many cell values into a smaller output. Like adding a set of counters. Here it produces category counts, annual counts, flags and support from the selected values.

engine/decision.py → summarize_counts()See it explained →

Registered plot

A boundary whose identity and selected cells are stored in advance. Like a saved delivery address. The registry avoids reselecting its geometry; a new or changed polygon must use the fresh-selection path.

engine/decision_index.py → build_registry(), registry_lookup()See it explained →

Resolution

The grid’s cell spacing. Like the square size on graph paper. Hansen’s step is 0.00025°, or 0.9 arc-seconds, about 28 m here. Finer resolution does not by itself establish a more correct legal answer.

engine/decision.py → nested_offsets()See it explained →

RSS

Resident set size: process memory held in physical RAM. Like the space a worker occupies at the bench. The reported peak RSS is a child-process lifetime high-water mark including Python and imports, not just the raster arrays.

engine/decision_benchmark.py → rss_record()See it explained →

Scanline

A row-wise way to find polygon membership. Like sweeping a ruler across graph paper. The fast selector uses row crossings for ordinary centres and exact GEOS covers near boundaries. It can be slower on boundary-heavy shapes.

engine/decision_index.py → fast_select_cells()See it explained →

Screening layer

The broader reduced contract. Like a checklist with an extra question. eudr-screen.v1 retains post-2020 Hansen loss on all land as well as the 2020 forest baseline and loss on that forest.

engine/decision.py → derive_screen_codes()See it explained →

SHA-256

A 256-bit cryptographic digest. Like a long reproducible fingerprint. It binds files, geometry and evidence to a specific version; a trusted pinned digest is needed to reject deliberate edits with recomputed self-hashes.

engine/source.py → sha256_file(), object_hash()See it explained →

Shapely / GEOS

Shapely is a Python geometry library backed by GEOS. Like a precise ruler for asking spatial questions. The query uses its polygon validation and boundary-inclusive covers predicate.

engine/query.py → select_cells()See it explained →

Sparse encoding

Store rare events rather than a value at every position. Like listing only the days it rained. The decision encoding records nonzero later-loss positions as gaps plus year symbols, alongside its class planes.

engine/decision_store.py → _split_parts(), _decode_split()See it explained →

Strip

A full-width block of raster rows inside a TIFF or a processing window. Like a horizontal slice through a page. Source Hansen files use strips; whole-tile processing also reads row windows to bound memory.

engine/decision_scale.py → read_strip()See it explained →

Support

How much usable information backs an answer. Like the lit fraction of a room being searched. Decision outputs use none, partial or complete. A yes can coexist with partial support; a zero count does not necessarily establish no.

engine/decision.py → summarize_counts()See it explained →

Tile

A geographical source-file piece, or a storage block within a TIFF. Like an atlas page versus a block on that page. Hansen source tiles span 10° × 10°; that does not imply the TIFF uses internally tiled blocks.

engine/decision_scale.py → tile_geometry(), run_scale()See it explained →

Tri-state

Three truth states: yes, no and unknown. Like found, ruled out and not fully checked. JSON outputs use true, false and null; null must not be displayed as zero or false.

engine/decision.py → summarize_counts(), nested tri()See it explained →

uint8

Unsigned 8-bit integer. Like a box limited to whole-number labels 0–255. Hansen bands and derived code rasters use this type. Compression changes stored bytes, not the decoded type’s range.

engine/source.py → open_sources()See it explained →

Varint

An integer encoded in a variable number of bytes. Like giving small numbers short labels. The codec uses seven payload bits per byte plus a continuation bit; decoding checks bounds before allocating arrays.

engine/decision_store.py → _varint(), _unvarints()See it explained →

Vector

Geometry described with coordinates rather than a cell grid. Like a traced outline. Farm polygons are vector data, combined with raster observations by testing cell-centre membership.

engine/query.py → select_cells()See it explained →

WGS84

The global reference framework used here for longitude and latitude. Like the agreed address book for Earth. These raster grids use its EPSG:4326 CRS; the query’s x/y convention is longitude then latitude.

engine/query.py → select_cells()See it explained →

zstd / Zstandard

A lossless compression method. Like a reversible packing recipe tuned for repeated patterns. v1 retains separate-band zstd at level 19; the decision store also compares zstd with other stream choices.

engine/codecs.py → encode_store()See it explained →
02 / The repository at a glance

Follow the answer through the files.

The engine is Python code that reads, encodes, queries and proves. The app is the React / TypeScript interface that shows the retained export and optional live-query results. React builds the interface from components; TypeScript adds type checks to JavaScript. These static explainer pages run independently of both.
