01 / The two ways to draw a map

Graph paper and a traced outline.

A raster is a rectangular grid of cells, like graph paper with a number in every square. A vector describes shapes with coordinates, like tracing a field boundary with a pen. Plotline combines them: raster layers supply observations; vector plot boundaries choose where to look.

A raster is an array.

8376091
8275590

Synthetic canopy values. A displayed green square is a colour chosen for a number; the source is not a photograph.

In code, an array is an ordered block of values. A cell has a row and column, counted from zero. Rows run down; columns run right. values[row, col] reads one number.

A vector is a shape.

Synthetic outline. Dots are vertices: the points joined by straight segments.

A polygon encloses an area. It can have an outer ring and inner rings called holes. Several separate polygons can form a MultiPolygon.

Bands are aligned sheets of numbers.

A band is one measured attribute on the grid. Think of a stack of graph-paper sheets: one for canopy, one for loss year, one for land or water. These Hansen bands arrive as three separate, single-band files. Plotline stacks their decoded values into a NumPy array shaped [3, height, width]. NumPy is Python’s library for working with number arrays.

uint8: a small number box.

A data type sets what values fit. uint8 means an unsigned 8-bit integer: one byte, with whole-number values from 0 to 255. Hansen uses only part of that range. This is a storage type, not a measurement unit.

Nodata: no usable observation.

Think of a blank answer on a form. Nodata and a false validity mask mean “unavailable”, not zero. A mask marks which numbers can be read as observations. Hansen’s datamask = 0 also explicitly means no data.

The acquired Hansen chips have no TIFF nodata value. Their per-band masks and datamask codes are still checked. A valid lossyear = 0 means no mapped loss; it does not mean missing.

02 / A numbered map in a file

What is inside a GeoTIFF?

A GeoTIFF is a TIFF image file with the labels needed to place its pixels on Earth. Think of a numbered mosaic in a labelled box: the pieces hold values; the labels say where the mosaic belongs and how large each piece is. A TIFF can hold several bands, or just one.

Rasterio is the Python map-file reader used here. It calls GDAL, a geospatial file library. In the original path, rasterio.open() reads the labels and src.read(1) decodes band 1. Plotline then queries the decoded arrays.

03 / From array addresses to Earth

A grid needs an address label.

A coordinate reference system (CRS) explains what map coordinates mean. Think of it as the address convention. Here WGS84, identified as EPSG:4326, describes positions in longitude and latitude degrees. Longitude runs east/west; latitude runs north/south. In the GeoJSON and raster x/y convention here, coordinates are [longitude, latitude].

An affine transform connects the grid’s row/column addresses to those coordinates. Think of a ruler laid across the mosaic: start at a known corner, then take one fixed step per column and row. The general transform has six coefficients and can include rotation; this query accepts only north-up grids without rotation.

Choose a synthetic cell.

Hover, click or focus a cell. Arrow keys move around the grid. Values are illustrative canopy percentages; coordinates use an invented origin.

● Cell centreRow ↓Column →
longitude = x₀ + (column + 0.5) × Δx
latitude = y₀ + (row + 0.5) × Δy

x₀ = 12°   y₀ = 6°   Δx = +0.00025°   Δy = −0.00025°

The origin is the upper-left outer corner. Adding 0.5 moves to the centre. The negative latitude step makes increasing rows move south. No company coordinates are used.

Precisely, Rasterio’s six coefficients are [a, b, c, d, e, f]. For pixel coordinates (u, v), x = a·u + b·v + c and y = d·u + e·v + f. Here b = d = 0, a > 0, e < 0. At a cell centre, u = column + 0.5 and v = row + 0.5.

The reverse lookup subtracts the origin and divides by the step: column = floor((longitude − x₀) / Δx), with the equivalent expression for row. This finds the containing cell. Selecting a plot instead asks which cell centres the polygon covers; that is the next chapter.

04 / Read the values

Hansen: three aligned grids.

Hansen Global Forest Change (GFC) is the public map product used here, version 2025 v1.13. Think of its bands as answers to three different questions at each address. They share a grid; the numbers have different meanings.

BandPlain meaning and exact codesWhat to avoid
treecover2000Canopy closure in 2000 for vegetation taller than 5 m. 0–100 is a percentage.A value of 80 is 80% canopy, not 80 trees or the 2020 forest class.
lossyearYear of mapped stand-replacement tree-cover loss. 0 = no mapped loss. 1–25 = 2001–2025; add 2000.A mapped loss is not a legal finding. One value does not describe every possible loss and regrowth event.
datamaskLand context: 0 = no data; 1 = mapped land; 2 = permanent water.Water is a known class. Do not treat it as unknown land or count it in the land-loss histogram.

22 → mapped loss in 2022

Try 0. A known “no mapped loss” is different from a masked or unavailable cell.

“Forest cover” in a dataset name is not a complete EUDR forest definition. Hansen records tree-cover change. JRC supplies the mapped 2020 forest class used in the screening rule. Their roles stay separate.

05 / Two grid sizes

Nine small cells inside one larger cell.

Resolution is the size of a grid cell, like the size of squares on graph paper. Hansen’s native step here is 0.00025°: exactly 0.9 arc-seconds, often rounded to “1 arc-second”. An arc-second is 1/3,600 of a degree. This is about 28 m at the sample’s latitude. Degrees are angles; the east–west ground distance per degree changes with latitude.

JRC GFC2020 is the Joint Research Centre’s mapped forest / non-forest baseline at 31 December 2020. We use v4. Its resolution is commonly called about 10 m (about 9 m here). On these aligned source grids, one Hansen cell contains exactly 3 × 3 JRC cells. This is a property checked for these grids, not a promise about arbitrary maps.

One Hansen footprint.

Click or press Enter / Space to flip a JRC class. The outlined middle cell shares the Hansen centre. All nine classes here are synthetic.

Three sampling choices.

Plotline uses the centre JRC cell. It does not average all nine and does not upsample the loss grid. Click a corner: “any forest” can change while the centre reading stays fixed.

The centre rule drops eight of the nine JRC values per Hansen footprint. It is a documented simplification. A sensitivity study found that centre, majority and any-forest sampling give the same presence flags on the 17 supplied plots. Only one plot has mapped 2020 forest, so that is a weak test of general suitability. Read the limitation.

Precisely, nested_offsets() checks an odd integer ratio, common CRS and aligned grid origins. With ratio 3 and a shared origin, Hansen (r, c) maps to JRC (3r + 1, 3c + 1). Chip origins add checked row and column offsets. If the grids do not meet the contract, the derivation refuses to resample them silently.

06 / Different meanings of “tile”

A tile is a page. A chip is a cut-out.

A source tile is one large geographical piece in a map product’s catalogue. Think of a page in an atlas. Hansen uses 10° × 10° tiles: with a 0.00025° step, each has 40,000 × 40,000 cells, or 1.6 billion cells.

A chip is a smaller rectangular window cut out of that tile. Here the Hansen chip is 1,233 columns × 604 rows, or 744,732 cells. It preserves the source step and moves the origin to the window’s upper-left corner. Acquisition checked the readback against the source pixel for pixel.

A TIFF’s internal storage tile is a different idea: one block of bytes inside a file. A geographic 10° source tile may be stored as TIFF strips. A chip may be written as tiled TIFF. The geography and the file layout are separate choices.

07 / The farm outline

GeoJSON stores the pen strokes.

A plot polygon is a farm outline drawn as a closed sequence of positions. Think of joining pegs with string. GeoJSON is a text format that stores that geometry, often together with named properties. The first and last position in each ring must be the same.

{
  "type": "Polygon",
  "coordinates": [[
    [12.0000, 6.0000], [12.0005, 6.0000],
    [12.0005, 5.9995], [12.0000, 5.9995],
    [12.0000, 6.0000]
  ]]
}

Invented positions for teaching only. These are not a supplied farm boundary.

One ring defines the exterior. Additional rings define holes, like a pond excluded from the farm. A MultiPolygon groups disconnected parts, like two separate fields. Shapely is the Python geometry library used to validate these shapes and test cell centres against them.

The outline is not resized into pixels. Plotline keeps the exact vector geometry and applies a fixed membership rule to the raster’s native centres. A small plot can select no centres even if it touches a cell’s footprint. Try the rule.

08 / Time matters

The cut-off separates state from change.

A cut-off date is the dividing line for the question. Think of a “before” photograph and an “after” log. For this EUDR screening use case, the baseline is forest at 31 December 2020; the available later loss years run from 2021 to 2025.

Up to 2020JRC’s 2020 forest class is the baseline authority.
2021 → 2025Hansen loss on that mapped baseline forest supplies the later-change signal.

Precisely, Hansen lossyear > 20 is post-cut-off. A Hansen loss before 2021 does not override a JRC 2020 forest cell: forest may have returned, or the maps may differ. The rule uses the JRC class as its mapped cut-off state.

The decision layer keeps mapped loss on mapped 2020 forest. Loss outside that forest class is kept in the broader screening layer, but dropped from the smaller decision layer. Its cause is not established by these layers.

This is a narrow mapped screening rule. It does not apply EUDR’s 0.5 ha minimum-area test or the “able to reach 5 m in situ” test. It does not cover protected areas, land rights or the full legal assessment.
