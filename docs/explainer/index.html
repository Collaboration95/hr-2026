The question behind every map

Was it forest at the end of 2020?
Has it been lost since?

A plot is a farm boundary. EUDR is the EU Deforestation Regulation. This project screens two mapped facts for that boundary: forest on 31 December 2020, then mapped loss from 2021 to 2025. The cut-off date separates the baseline from later change.

01 / The ingredients

Three kinds of evidence.

Public / Hansen

Canopy, loss, land.

Hansen Global Forest Change (GFC) 2025 v1.13 provides canopy cover in 2000, one loss-year code for 2001–2025, and a land/water mask. Its cells are about 28 metres here.

Public / JRC

A 2020 baseline.

The European Commission’s Joint Research Centre (JRC) GFC2020 v4 map says forest or non-forest at the cut-off. It is about 10 metres, with a grid that nests 3×3 inside Hansen cells.

Company sample / local only

17 plot boundaries.

SystemEarth supplied 17 farm polygons and matching due-diligence records. A polygon is a closed outline made from coordinate pairs. We use synthetic outlines throughout these pages.

How an outline becomes data →

Think of the layers as transparent sheets stacked on graph paper. Precisely, they are arrays of numbers tied to locations on Earth. The plot tells us which locations to inspect; each layer supplies a different fact at those locations.

03 / The change in approach

Keep the decision, not the data.

The first build packed the whole suitcase more tightly: it kept every raw Hansen value and validity mask, the marker saying whether a value is usable. This is lossless: every value can be restored exactly. It was 8.6% smaller, with no hot-path speedup. “Hot” means the maps are already decoded in memory, ready to query.

The next build first asks what the traveller needs. It replaces each map cell with one small code containing the facts the screening rule reads. Exact canopy percentages and older loss years can stay in the audit archive.

A registered plot has its boundary saved in advance. A cell index remembers which grid positions it selects; an answer table stores its completed outputs. Both avoid repeated work. A new boundary still needs fresh selection.
