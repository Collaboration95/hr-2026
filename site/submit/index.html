Go deeper: what each script really does technical

    
setup-local.sh needs python3.14 (or PLOTLINE_PYTHON) and Node. It creates .venv-data, installs engine/requirements.txt and runs npm ci --prefix app.

    
verify-local.sh checks the private data is present, confirms Python 3.14, runs engine.verify and engine.jrc --verify, queries P-0003 against the retained compact store two ways, re-runs the decision-layer proof into a temporary file, and builds the app. It does not rebenchmark.

    
Deep links once the app is up: #/map, #/map/P-0001/2022, #/cohort, #/proof/P-0005/2025, #/live. Map, Cohort and Proof work offline from a frozen export; Live query needs the optional local API on port 8765.

High

The build copies demo-v1.json (about 1.5 MB, containing the plot geometries) into app/dist/data/. app/README.md still says the build "includes the supplied company sample" and that publication is authorised, which is out of date since the repository went private on 15 October. This explainer pack contains no plot geometry; app/dist does.
Fix: never deploy app/dist; update the sentence in app/README.md.

    
Medium

The repository is private (gh repo view: PRIVATE), so judges and the company cannot open it. A fresh clone also needs the 31-file private bundle, and nobody has confirmed where the current bundle is stored. GitHub Pages from a private repository depends on the owner's plan, which we have not checked.
Fix: run scripts/private-data.sh pack now to a private location and confirm a second teammate can unpack it. Decide how the pitch is shown (live app, recording, slides).

AGENTS.md still says no track is selected and that "no runtime, package manager, build, or test commands exist yet". Both are wrong now. engine/README.md has run-together words ("Python3.14", "and17supplied").

Python must be exactly 3.14 (setup-local.sh and verify-local.sh both refuse anything else) and shapely is pinned because the fast selector calls its internals directly. The live query service is optional, so keep the offline views as the demo path.
