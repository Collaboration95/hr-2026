What each script does technical

    
setup-local.sh needs python3.14 (or PLOTLINE_PYTHON) and Node. It creates .venv-data, installs engine/requirements.txt and runs npm ci --prefix app.

    
verify-local.sh checks the private data is present, confirms Python 3.14, runs engine.verify and engine.jrc --verify, queries P-0003 against the retained compact store two ways, re-runs the decision-layer proof into a temporary file, and builds the app. It does not rebenchmark.

    
Deep links once the app is up: #/map, #/map/P-0001/2022, #/cohort, #/proof/P-0005/2025, #/live. Map, Cohort and Proof work offline from a frozen export; Live query needs the optional local API on port 8765.

High

Medium
Plot outlines remain in the live app and the local recordings
On 16 Oct the 76 screenshots and WebM recordings were removed from git and its history and are now ignored, so they exist only on the team laptop. The live app still draws the outlines. Whether the supplied sample may appear in slides or a public demo is an open question to SystemEarth.
Fix: ask SystemEarth (question 8 below); until answered, show the app only to the company's own team and do not publish recordings.

    
High
app/dist is not for hosting
The build copies demo-v1.json (about 1.5 MB, containing the plot geometries) into app/dist/data/. app/README.md was corrected in commit 77e95b9 and now says never to publish or deploy app/dist/. This explainer pack contains no plot geometry; app/dist does.
Fix: app/dist is never deployed.

    
Medium
The repository is public, but only teammates can run it
The repository was made public on 16 Oct, so judges and the company can read it. A fresh clone cannot run anything without the 31-file private bundle, and where the current bundle is stored is unconfirmed.
Fix: run scripts/private-data.sh pack to a private location and confirm a second teammate can unpack it. Decide how the pitch is shown (live app, recording, slides).

    
Medium
The explainer pack is committed but not published
site/ is committed on branch guru/explainer-pack. Publication requires pushing that branch. GitHub Pages from a private repository depends on the owner's plan, which has not been checked. The .gitignore line for app/.vite/ was committed in 77e95b9.
Fix: push the branch and confirm the Pages plan, or share the pack another way.

    
Low
Environment is strict
Python must be exactly 3.14 (setup-local.sh and verify-local.sh both refuse anything else) and shapely is pinned because the fast selector calls its internals directly. The live query service is optional; the offline views work without it.

    
Low
Documentation links are healthy
Every relative Markdown link in the 102 Markdown files outside the dependency folders was checked: 0 broken. External URLs were not checked. Numbers in the README, writeups, pitch and the app's decision summary agree with the Phase 4 report.

    
Resolved

AGENTS.md no longer says that no track is selected or that no build or test commands exist. app/README.md no longer says publication is authorised. engine/README.md no longer has run-together words ("Python3.14", "and17supplied"). All three were corrected in commit 77e95b9.
